# ASSETS_NEEDED.md — Screw Jam 3D 3D Models & Textures

> All assets are **100% procedurally generated by default** using Three.js compound geometries (`ExtrudeGeometry`, `LatheGeometry`, procedural canvas textures).  
> The game runs fully standalone without any external asset downloads (`dist/` < 2 MB).  
> The optional `.glb` models below can be dropped into `public/models/` to seamlessly hot-swap the procedural prefabs.

---

## 1. Optional User Models (`public/models/`)

| File Name | Target Entity | Max Triangle Budget | Textures / Format | Purpose |
|---|---|---|---|---|
| `screwdriver_tool.glb` | Unbolting tool | < 1,500 tris | PBR Metallic/Roughness, 512×512 | Animates spinning and unscrewing when tapping a screw. |
| `screw_head.glb` | Color-coded screw | < 800 tris | Stylized Toony, Vertex Colors or 256×256 | Replaces procedural LatheGeometry bolt mesh. |
| `toolbox_container.glb` | 3-slot toolbox | < 1,200 tris | Matte vinyl finish, 512×512 | Replaces procedural 3D box tray. |
